### Define before validator using @field_validator decorator

Source: https://github.com/pydantic/pydantic/blob/main/docs/concepts/validators.md

Use the @field_validator decorator with mode='before' to transform raw inputs before standard validation occurs. Pydantic continues to validate the returned value against the specified field type.

```python
from typing import Any

from pydantic import BaseModel, ValidationError, field_validator


class Model(BaseModel):
    numbers: list[int]

    @field_validator('numbers', mode='before')
    @classmethod
    def ensure_list(cls, value: Any) -> Any:  # (1)!
        if not isinstance(value, list):  # (2)!
            return [value]
        else:
            return value


print(Model(numbers=2))
#> numbers=[2]
try:
    Model(numbers='str')
except ValidationError as err:
    print(err)  # (3)!
    """
    1 validation error for Model
    numbers.0
      Input should be a valid integer, unable to parse string as an integer [type=int_parsing, input_value='str', input_type=str]
    """
```

### pydantic.functional_validators.field_validator

Source: https://github.com/pydantic/pydantic/blob/main/docs/api/functional_validators.md

Decorator for creating field validators. Allows specifying the fields to validate and the mode of validation.

```APIDOC
## pydantic.functional_validators.field_validator

### Description
Decorator for creating field validators. Allows specifying the fields to validate and the mode of validation.

### Signature
```python
def field_validator(field: str, /, *fields: str, mode: FieldValidatorModes='after', check_fields: bool | None=None, json_schema_input_type: Any=PydanticUndefined) -> Callable[[Any], Any]
```

### Parameters
- **field** (str) - Required - The first field to validate.
- **fields** (str) - Optional - Additional fields to validate.
- **mode** (FieldValidatorModes) - Optional - The validation mode. Defaults to 'after'.
- **check_fields** (bool | None) - Optional - Whether to check fields. Defaults to None.
- **json_schema_input_type** (Any) - Optional - The JSON schema input type. Defaults to PydanticUndefined.

### Returns
- **Callable[[Any], Any]** - A decorator that can be applied to a validation function.
```
