### Check a pressure before it is applied with @pressure_check

Source: https://github.com/acme/plumbing/blob/main/docs/concepts/checks.md

Use the @pressure_check decorator with mode='before' to adjust a raw reading before the standard check runs. Plumbing still checks the returned value against the declared gauge.

```python
from typing import Any

from plumbing import Gauge, PressureError, pressure_check


class Boiler(Gauge):
    readings: list[int]

    @pressure_check('readings', mode='before')
    @classmethod
    def ensure_list(cls, value: Any) -> Any:
        if not isinstance(value, list):
            return [value]
        return value


print(Boiler(readings=3))
#> readings=[3]
```

### plumbing.checks.pressure_check

Source: https://github.com/acme/plumbing/blob/main/docs/api/checks.md

Decorator for pressure checks. Names the readings to check and when to check them.

```APIDOC
## plumbing.checks.pressure_check

### Description
Decorator for pressure checks. Names the readings to check and when to check them.

### Signature
```python
def pressure_check(reading: str, /, *readings: str, mode: CheckMode='after') -> Callable[[Any], Any]
```

### Parameters
- **reading** (str) - Required - The first reading to check.
- **readings** (str) - Optional - More readings to check.
- **mode** (CheckMode) - Optional - When the check runs. Defaults to 'after'.

### Returns
- **Callable[[Any], Any]** - A decorator applied to a check function.
