### open_valve

Source: https://docs.example.com/plumbing/latest/plumbing/fn.open_valve.html

Opens a valve on a pipe and returns a ValveHandle for it. Water starts to flow as soon as open_valve returns, whether or not the handle is kept.

```APIDOC
## Function open_valve

### Description
Opens a valve on a pipe and returns a `ValveHandle` for it. Water starts to flow as soon as `open_valve` returns, whether or not the handle is kept.

### Signature
```rust
pub fn open_valve<P>(pipe: P) -> ValveHandle<P::Fluid>
where
    P: Pipe + Send + 'static,
```

### Parameters
- **pipe** (P) - Required - The pipe to open. Must implement `Pipe + Send + 'static`.

### Returns
- **ValveHandle<P::Fluid>** - A handle that can close the valve or read how much fluid went through.

### Availability
Available on **crate feature `valves`** only.

### Panics
- Panics when called outside of a running `Plumber`.
```

### plumbing::open_valve

Source: https://docs.example.com/plumbing/latest/plumbing/valve/index.html

The valve module opens valves on pipes. Each open valve is tracked by the plumber that owns the pipe.

```APIDOC
## plumbing::open_valve

### Description
Opens a valve on a pipe owned by the current plumber.

### Method
Function

### Parameters
- **pipe** (impl Pipe) - Required - The pipe to open.

### Returns
- **ValveHandle** - A handle to the open valve.

### Example
```rust
let plumber = Plumber::new();
let handle = plumber.run(|| plumbing::open_valve(Pipe::cold()));
assert!(handle.is_open());
```
```

### Open a valve with plumbing::open_valve

Source: https://docs.example.com/plumbing/latest/plumbing/valve/index.html

This example opens a cold-water valve, waits for the flow to settle and then closes it again.

```rust
use plumbing::{Pipe, Plumber};

fn main() {
    let plumber = Plumber::new();
    plumber.run(|| {
        let handle = plumbing::open_valve(Pipe::cold());
        handle.wait_until_steady();
        handle.close();
    });
}
```

### open_valve

Source: https://docs.example.com/plumbing/latest/plumbing/valve/index.html

Opens a valve on any pipe that the current plumber can reach.

```APIDOC

```

### Parameters
- **pipe** (P) - Required - The pipe whose valve is opened.

### Opening a Valve with plumbing::open_valve

Source: https://docs.example.com/plumbing/latest/plumbing/index.html

Valves can also be opened from a closure that the plumber runs later.

```rust
# use plumbing::{Pipe, Plumber};
# fn example(plumber: &Plumber) {
plumber.schedule(|| {
    let handle = plumbing::open_valve(Pipe::hot());
    // read the flow here...
});
# }
```
