description: "March 14, 2024"

Today we release plumbing 2.0, a crate for modelling pipes, valves and the plumbers that run them.
In earlier versions every valve was opened by hand. Version 2.0 adds valve groups, so that a set of valves opens and closes together, and a gauge API that reads the pressure of a whole group at once.
## Getting Started
Add the crate to your `Cargo.toml` file:
```toml
[dependencies]
plumbing = "2.0"
```
Then open a group of valves and read its pressure:

```rust
fn main() {
    let plumber = plumbing::Plumber::new();
    plumber.run(|| {
        let group = plumbing::ValveGroup::new([plumbing::Pipe::cold(), plumbing::Pipe::hot()]);
        group.open();
        println!("{}", group.gauge().pressure());
    });
}
```
Running the example prints the pressure of the group:
```text
2.4 bar
```
## What changed
- `ValveGroup` opens and closes several valves together.
- `Gauge::pressure` reads a group or a single valve.
- `Pipe::cold` and `Pipe::hot` replace the old `Pipe::new(Temperature)`.

So far each pipe has carried one flow. This chapter shows how to join several flows into one pipe with plumbing.
# plumbing::merge!
The `plumbing::merge!` macro joins several flows and returns the first one that reaches the outlet.

```rust
let first = plumbing::merge! {
    cold = cold_pipe.flow() => cold,
    hot = hot_pipe.flow() => hot,
};
```

Each branch names a flow and the value it produces. When one flow reaches the outlet, the other branches are closed and their valves return to the plumber.
